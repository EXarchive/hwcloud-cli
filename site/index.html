Terraform · Huawei Cloud OBS

这个站点是「一条命令」交付的

桶、静态网站配置、对象上传、防盗链与 IP 黑名单全部由 Terraform 声明。 没有一次手工点控制台，改配置再 terraform apply 即可得到一致结果。

① 声明式交付

桶 ACL、website 首页/错误页、对象 Content-Type 与 ETag 全在 main.tf 里声明，状态可追溯、可回滚。

② 访问控制

公开只读 + 可选防盗链白名单 + 桶策略 IP 黑名单，三层控制互不打架，随变量开关。

③ 幂等可重跑

用 filemd5 作 ETag，内容未变不会重复上传；新增文件自动纳入 for_each。

交付命令
cd terraform
terraform init
terraform plan  -var="bucket_name=my-ict-site-2026"
terraform apply -var="bucket_name=my-ict-site-2026"
# 输出 website_endpoint 即访问地址
静态资源已随仓库提交，ip_blacklist 与 allowed_referers 默认关闭。
